## 额外可靠性检查

- 六种状态均可体验：未启动、启动中、运行中、停止中、已停止、启动失败。不存在用 Ready / Working 猜 AI 状态的逻辑。
- 单会话启动失败不影响其他会话；停止失败不会删除配置或伪报已停止；异常退出保留退出码。
- 启动中停止后不会被启动回调复活；输出与退出拒绝过期 runId。
- 每个会话保存本页草稿和滚动位置；浏览旧输出时不跳底，“回到最新”有效。
- 后台达到 5000 行并继续裁剪时，仍保留的可见内容位置保持；锚点内容已被裁掉时显示最早保留行。
- 新建连点只创建一次；在其他目录新建沿用工具，旧会话及原运行保持。
- 保存空列表后刷新仍为空；输出、草稿、运行 ID 与历史指令不进入持久配置。
- 模拟浏览器存储写失败，界面显示“配置未保存”；恢复后重试可保存。损坏配置不被种子静默覆盖。
- 模拟中文组合输入中的 Enter 不发送，Shift+Enter 可换行；键盘焦点有可见轮廓。
- 长中文路径曾在实测触发外层 Grid 横向撑宽，修复最小列宽后回归通过。

## 已知限制与证据边界

1. 这是 Mock，不是桌面应用。目录仅模拟，未验证本机目录存在性、符号链接、权限及 Windows 大小写目录身份。
2. 配置保存在当前浏览器的 localStorage。不同浏览器/资料/文件位置不共享；存储禁用或空间不足会有提示。刷新不保留本页终端全文及草稿，这是设计行为。
3. 5000 行回滚与模拟定时器隔离已验证；真实 PTY、ACK、背压、Windows 子进程清理均未实现或实测。
4. 组合输入事件保护已自动化检查；真实中文输入法候选框、Windows 125%/150% 显示缩放、系统剪贴板和多显示器仍需真实桌面阶段验证。
5. 本轮没有安装/执行 Agent Workbench，没有启动三种真实 CLI，也没有验证 EXE、安装器、桌面快捷方式或单实例行为。源码阅读、状态测试及本次浏览器通过不代替这些验收。
6. 当前未发现阻断本阶段交互体验的问题；用户体验尚未确认。
