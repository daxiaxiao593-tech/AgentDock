# Agent Desk Implementation Plan

> 实施时使用 writing-plans 对应的 executing-plans 流程逐项核验。本轮交付文档，后续按用户已确认的“Mock → 复用验证 → 真实桌面”顺序实施。

**Goal:** 交付能由桌面快捷方式打开、统一管理 Codex / Antigravity / Claude Code 的 Windows 单窗口工具。

**Architecture:** 优先定向改造 Agent Workbench 固定版本，保留 Node 服务与 React/xterm 终端分层，增加桌面外壳。只有复用边界验证通过，才采用该底座；不通过则采用成熟终端组件构建薄壳。

**Tech Stack:** Mock 为既有 HTML/CSS/JS；优先路线为 Electron + Node/Express/ws + React/xterm.js + node-pty。版本与 ABI 经实验后锁定。

**Spec:** [产品与交互设计稿](./01-产品与交互设计稿.md)、[技术方案与开源选型](./03-技术方案与开源选型.md)。本稿替代历史版本中的“直接新建独立桌面工程”次序。

## Global Constraints

- 三种工具、真实目录分组、独立会话、左侧树、后台继续运行。
- 桌面单实例，不重复启动；不要求用户先运行命令行。
- 不更改 CLI 权限默认值，不自动确认，不重发历史提示，不默认恢复模型对话。
- 聚合壳首版不扫描原生历史、不保存额外 CLI 日志、不启用状态 hooks；CLI 自身行为保持。
- 保留六种生命周期状态，后台仅显示新输出；不猜 AI 语义状态。
- 配置与运行实例分离，sessionId/runId 隔离事件；5000 行回滚之外需控制传输队列。
- 保留 CLI 原认证；不复制密钥、不存自定义环境、不引入模型网关。
- 同目录多会话提示共享文件，首版不自动 worktree、不加编辑器、分屏、远程访问或托盘。

## 2. 任务 1：Mock 交互定稿

**输入：**产品稿与现有 HTML。**输出：**同一份可预览 Demo 与验收记录。

- [ ] 重现并修正浅拷贝状态、共享目录被改写、异步回复串台和换目录文案问题。
- [ ] 每次创建独立选模拟目录，自动归组；同目录显示共享文件提示，空分组自动消失。
- [ ] Mock 输出由 sessionId/runId 路由；保存各会话草稿和滚动位置；切换不停止其他模拟运行。
- [ ] 完成启动全部、单会话启动/停止/移除、自动启动勾选、六种状态和错误示例。
- [ ] 保存定义到 localStorage；刷新重建模拟运行，不重发旧输入，已保存空列表不重置。
- [ ] 持续显示模拟标签；不虚构真实额度/模型/任务成功；目录选择不用文件上传冒充原生选择。
- [ ] 按产品稿 8 步验收，补测同目录提示和停止后快速重启；覆盖 1440×900、960×640、长中文路径及键盘焦点。

**通过条件：**无串台、目录互不改写、刷新配置恢复、所有新增输出明确模拟；记录实际结果给用户体验。

## 3. 任务 2：复用边界验证

**输入：**固定 upstream commit。**输出：**`UPSTREAM.md`、改动边界报告及继续/退出整体 fork 的结论。

- [ ] 克隆固定版本到隔离源码目录，记录 commit 与 LICENSE；先读依赖安装脚本、项目说明和模拟脚本，尚未审查的脚本不直接运行。
- [ ] 查明三工具 launch/onSpawned/prepare/environment 的全部行为，列出会写终端、扫描历史、创建日志和修改环境的入口。
- [ ] 在假 CLI 与隔离 HOME 下验证纯终端模式，断言不注入权限参数、不自动写任何确认、不扫描真实用户目录。
- [ ] 执行通过审查的上游 `pnpm demo`，确认模拟 CLI 选择方式不会回退到真实 CLI；未满足隔离条件则先修正再执行。
- [ ] 评估新定义源能否通过局部接入复用原注册表，而非复制或重写主要生命周期。
- [ ] 形成清晰裁决：可局部改造则继续；必须重写生命周期、适配器和传输三大核心则退出整体 fork，走组件复用路线。不得一边判定不可复用，一边继续大规模重写。

**检查命令：**沿用上游 `pnpm typecheck`、`pnpm check`，为纯终端路径新增对应检查；不把上游成功徽章记为本地运行结果。

## 4. 任务 3：三 CLI 接入与生命周期

**输入：**通过任务 2 的底座。**输出：**真实 CLI 独立运行、目录正确、原权限行为保持。

**接口契约：**`start(sessionId)` 只从已验证定义解析命令和 cwd；`stop(sessionId, runId)` 结束对应运行；`write/resize(sessionId, runId, ...)` 拒绝过期运行。状态事件含 runId，数据事件另含 seq；消费 ACK 不得跨运行使用。

- [ ] 先建立回归：A 输出不落 B；旧 runId 输出和 exit 被忽略；重复 start 只创建一次；启动中取消不遗留进程。
- [ ] 补齐三种入口解析，用本机已发现 codex.cmd/agy.exe/claude.exe 核验。cwd 单独传入，参数不拼接任意 shell 字符串。
- [ ] 使用可控测试 CLI 证明“无人工输入时，聚合壳不发送任何任务或确认文本”。
- [ ] 实机验证三个 CLI 的中文/空格目录、登录提示、权限提示、Ctrl+C、多行粘贴、resize、双实例；仅使用测试项目，不让验证任务改动用户项目。
- [ ] 失效目录保留配置并报错；同名不同路径明确区分；盘符/尾分隔符规范化与大小写敏感目录分别验证。
- [ ] 接入有界输出队列/ACK/背压，测试高速输出时前台可输入，后台持续消费且无无界增长；阈值与机器参数记录在报告。
- [ ] 停止等待实际退出与所属进程清理；测试 CLI 拉起子进程的情形，确保其他独立终端存活。

**通过条件：**测试报告分别记录三 CLI 版本、路径、输入和退出结果；一种失败不妨碍其他。若无法稳定关闭所属进程，该阶段不通过。

## 5. 任务 4：桌面外壳

**输入：**稳定的本机终端服务。**输出：**独立 Windows 窗口及桌面运行回归。

**接口契约：**父子私有通道 `ready {origin, token}` / `shutdown` / `stopped`；协议只用于所属服务。浏览器不获得任意进程管理 API。

- [ ] 单实例锁在启动服务前取得；第二次启动只聚焦已有窗口，不能再建服务或启动会话。
- [ ] 使用固定随包运行时启动隐藏服务；收到 ready 后才加载窗口，超时显示错误。
- [ ] 保留本机随机端口、令牌、Origin/Host 检查；窗口限制导航；目录选择走最小 preload API。
- [ ] 从独立 userData 恢复 Workspace，按 launchOnOpen 启动；未勾选的保持未启动。
- [ ] 渲染重载重连同一个 run，测试屏幕重建是否可靠；不依赖截断 ANSI 日志作为完整终端快照。
- [ ] 验证退出确认、取消退出、服务崩溃、主进程被结束、睡眠/唤醒和断网；不自动重发提示或重试任务。
- [ ] 测试 125%/150% 缩放、跨显示器变化、中文候选框位置、复制快捷键、后台未读提示；图片输入只记录实际兼容性。

**通过条件：**重复打开不重复运行，正常退出无所属进程残留，异常行为明确可见；开发环境与桌面入口行为一致。

## 6. 任务 5：安装包与快捷方式

**输入：**通过任务 4 的桌面程序。**输出：**安装包、真实桌面快捷方式、简短使用说明和验收记录。

- [ ] 锁定运行时、包管理器和 native addon 构建环境，保存 lockfile；Node 服务加载的原生模块与该 Node ABI 对齐。
- [ ] 安装器创建稳定 EXE 入口和 Desktop Known Folder 下的快捷方式；不硬编码桌面路径、不把版本号 CLI 路径写入快捷方式。
- [ ] 从快捷方式冷启动，不先开终端/IDE/开发服务器；验证无额外命令窗口，三工具按配置启动。
- [ ] 重复双击、注销后重新登录再打开、配置为空和 CLI 不存在分别验收；工作台不自动安装目标 CLI。
- [ ] 检查升级保留配置；卸载不删除用户项目或三 CLI 的历史/认证。
- [ ] 附第三方许可、上游版本和改动清单；签名/系统提示如实记录。

**通过条件：**用户只需双击桌面入口即可使用真实程序。HTML 预览、安装器构建成功或开发窗口都不能代替此项验收。
