# Agent Desk Implementation Plan

> 实施按各阶段验收逐项核验；任务 4 的跨显示器移动及终端选中文本后的 Ctrl+C 保持为独立待验项。

**Goal:** 交付能由桌面快捷方式打开、统一管理 Codex / Antigravity / Claude Code 的 Windows 单窗口工具。

**Architecture:** 已按复用边界报告退出 Agent Workbench 整体 fork，采用 AgentDock 自有 Node Runtime、Windows ConPTY 和 xterm.js 页面；Electron 主进程管理单实例窗口，并以独立固定 Node 运行时启动隐藏本机服务。

**Tech Stack:** Electron 44.9.0、独立 Node 24.22.0 运行时、Node.js、ws、xterm.js、node-pty / Windows ConPTY。Electron 与服务分开运行，node-pty 按固定 Node ABI 构建；界面为现有 HTML/CSS/JS，不使用 React。

**Spec:** [产品与交互设计稿](./01-产品与交互设计稿.md)、[技术方案与开源选型](./03-技术方案与开源选型.md)。本稿替代历史版本中的“直接新建独立桌面工程”次序。

## Global Constraints

- 三种工具、真实目录分组、独立会话、左侧树、后台继续运行。
- 桌面单实例，不重复启动；不要求用户先运行命令行。
- 不更改 CLI 权限默认值，不自动确认，不重发历史提示，不默认恢复模型对话。
- 聚合壳首版不扫描原生历史、不保存额外 CLI 日志、不启用状态 hooks；CLI 自身行为保持。
- 保留六种生命周期状态，后台仅显示新输出；不猜 AI 语义状态。
- 配置与运行实例分离，sessionId/runId 隔离事件；5000 行回滚之外需控制传输队列。
- 保留 CLI 原认证；不复制密钥、不存自定义环境、不引入模型网关。
- 同目录多会话提示共享文件，首版不自动 worktree、不加编辑器、分屏、远程访问或托盘。

## 5. 任务 4：桌面外壳

**输入：**稳定的本机终端服务。**输出：**独立 Windows 窗口及桌面运行回归。

**接口契约：**父子私有通道 `ready {origin, token}` / `shutdown` / `stopped`；协议只用于所属服务。浏览器不获得任意进程管理 API。

- [x] 单实例锁在启动服务前取得；第二次进程退出并聚焦已有窗口，不会重复创建服务或会话。
- [x] 使用固定 Node 运行时启动隐藏服务；收到 ready 后才加载窗口，超时显示明确错误。
- [x] 保留随机本机端口、令牌、Origin/Host 检查；窗口限制导航；目录选择只通过最小 preload API。
- [x] 从 Electron 独立 userData 恢复工作目录和 launchOnOpen；未启用的 CLI 保持未启动。
- [x] Renderer 重载后读取同一个 run 快照，不扫描或重发提示，不自动重试任务。
- [x] 自动化验证正常退出、取消退出、服务异常退出与主进程异常结束；服务崩溃不自动重启。CDP 离线模拟确认 localhost 控制界面/服务保持可用。
- [x] 实体机器验证睡眠/唤醒及真实 Wi-Fi 断连：S0 唤醒后服务和原 PTY 进程仍在，WebSocket 已断；手动重载 Renderer 后恢复同一 run 快照且未重发提示。断网期间 loopback 服务仍返回 HTTP 200；Wi-Fi 已恢复。唤醒时机异常延迟且唤醒原因未能确认，详见开发记录。
- [x] 通过 CDP 以 125%/150% 设备缩放检查无水平溢出；Renderer 测试覆盖后台未读标记。
- [x] 实机验证微软拼音候选框贴合终端光标且可见；验证应用界面选中文本后 Ctrl+C 可复制。
- [ ] 验证跨显示器移动；当前机器只有一个活动物理显示器。终端文本选择后的 Ctrl+C 也尚未单独验证。

**当前状态：部分完成。** 单实例、ready 门槛、退出/崩溃收尾、配置恢复、Renderer 重连、缩放模拟，以及睡眠/唤醒、真实 Wi-Fi 断连、IME 候选框和应用界面复制均有验证记录；跨显示器与终端文本选择后的复制仍待验证。
