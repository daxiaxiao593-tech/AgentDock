**Tech Stack:** Electron 44.9.0、独立 Node 24.22.0 运行时、Node.js、ws、xterm.js、node-pty / Windows ConPTY。Electron 与服务分开运行，node-pty 按固定 Node ABI 构建；界面为现有 HTML/CSS/JS，不使用 React。

**Spec:** [产品与交互设计稿](./01-产品与交互设计稿.md)、[技术方案与开源选型](./03-技术方案与开源选型.md)。本稿替代历史版本中的“直接新建独立桌面工程”次序。

## Global Constraints

- 三种工具、真实目录分组、独立会话、左侧树、后台继续运行。
- 桌面单实例，不重复启动；不要求用户先运行命令行。
- 不更改 CLI 权限默认值，不自动确认，不重发历史提示，不默认恢复模型对话。
- 聚合壳首版不扫描原生历史、不保存额外 CLI 日志、不启用状态 hooks；CLI 自身行为保持。
- 保留六种生命周期状态，后台仅显示新输出；不猜 AI 语义状态。
- 配置与运行实例分离，sessionId/runId 隔离事件；5000 行回滚之外需控制传输队列。
- 保留 CLI 原认证；不复制密钥、不存自定义环境、不引入模型网关。
- 同目录多会话提示共享文件，首版不自动 worktree、不加编辑器、分屏、远程访问或托盘。
