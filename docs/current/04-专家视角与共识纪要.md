# 专家视角、遗漏检查与 Antigravity 共识

2026-10-17 · 本轮使用本机 `agy.exe` 实际讨论；没有联系外部专家本人。

## 1. 为什么选择 Mitchell Hashimoto 作为参照

Mitchell 是 Ghostty 的创建者，其公开文章讨论终端兼容性、性能、平台原生体验，以及将终端能力拆成可复用基础组件。[Ghostty 目标](https://mitchellh.com/writing/ghostty-is-coming) · [Libghostty 复用思路](https://mitchellh.com/writing/libghostty-is-coming)

我们据此作出的推演：把精力放在项目和会话管理，复用成熟终端；用实际键盘、中文和窗口体验判断完成度；界面与运行生命周期分离；先做好个人 Windows 小版本。此推演不代表他会选择 Electron，也不构成对本项目或某个 GitHub 仓库的背书。

## 2. 与 Antigravity 的实际讨论

本轮增加四次非交互文字评审，均使用计划模式、沙箱与禁用 slash commands，要求不执行工具和文件修改：

| 轮次 | 内容 | 结果 |
|---|---|---|
| 3 | 用户认可的专家建议与遗漏清单 | 大方向同意，提出右键菜单、状态简化、额外配置和许可证筛选等建议 |
| 4 | Codex 纠正超出范围或不够准确的建议 | Antigravity 明确同意八项首版约束 |
| 5 | 传入候选仓库、许可证、固定版本及源码差异 | 同意有条件首选 Agent Workbench，要求验证改造范围与服务生命周期 |
| 6 | 修正 `.cmd` 实际存在、许可证措辞、证据等级和交付边界 | 最终确认见讨论记录；设计共识不等于运行验证 |

完整问答以整理后的 Markdown 保存在 `讨论记录/`，保留输入上下文与实际 response。没有把 CLI 的推测直接当作本机验证，也没有采用其所有建议。

## 3. 达成的共识

1. 首版桌面单窗口、单实例；重复打开仅唤起原窗口。不加右键菜单、目录启动参数转发和开机自启。
2. 项目即真实目录；会话独立创建后归组；同目录共享文件明确提示，不自动创建 worktree。
3. 六种状态描述进程生命周期，后台只有新输出标记；不解析 ANSI 文本猜 AI 状态，不以 hooks 为首版前提。
4. 只保存会话定义和选中项，不保存密钥、任意环境变量或额外终端全文；启动不自动续聊或重放指令。
5. 不自动覆盖 CLI 权限设置，不自动答复对话框。原工具自己的认证、历史、网络调用仍正常工作。
6. 输出有界队列和消费确认/背压，与 5000 行回滚分别设计；不能靠丢弃控制序列减压。
7. Windows 进程树处理只针对本应用创建的进程；正常和异常退出均需实测，不假设一次 kill 必然完成清理。
8. 先调查复用，再选择底座；有条件首选 Agent Workbench 固定版本，接受退出整体 fork 的明确门槛。
9. 先 Mock，再真实接入和桌面打包；快捷方式必须指向实际程序，不能用 HTML 链接代替最终交付。

## 4. 讨论中纠正的意见

| 原意见 | 最终处理 |
|---|---|
| 二次启动支持目录参数和右键菜单 | 超出当前需求，删除 |
| 状态只留运行/退出 | 保留启动中、停止中和启动失败，删除的是 AI 语义猜测 |
| 保存自定义 env 与 args | 只保存最小定义；启动参数由已验证适配器管理 |
| 默认排除 GPL/AGPL | 不一概排除，逐项目看实际许可与复用方式 |
| 节流渲染即可控制大量输出 | 增加有界队列和端到端背压要求 |
| tday 许可证被描述为限制性 | 仅记录自定义 SNTS v2/NOASSERTION，不自行作法律定性 |
| 本机 Codex 可能只有 ps1 | 只读核验发现 cmd 确实存在，改为验证调用链及路径引用 |
| 上游链路已跑通 | 作者资料、源码结构、上游 CI 与本机实测分列；本轮没有运行候选 |

## 5. 遗漏清单及落点

| 问题 | 处理与验收 |
|---|---|
| 多次双击开出多组工具 | 服务启动前取得单实例锁，快捷方式重复打开回归 |
| 多 Agent 改同一文件 | 共享目录标记；用户自行协调，首版不承诺文件隔离 |
| 启动与继续对话混淆 | 保存定义与原生历史分开；不自动重发/恢复 |
| 后台等待确认没被注意 | 新输出未读标记，不虚构等待状态 |
| 大量输出拖垮窗口 | 有界输出、消费 ACK、前后台压力测试 |
| 崩溃/睡眠/断网 | 分情况提示与重连；不自动重试任务 |
| CLI 更新或入口变化 | 单工具失败隔离、记录已测版本、避免写死桌面包版本目录 |
| Windows 缩放与中文 | 125%/150%、IME、多行粘贴、复制快捷键作为硬验收 |
| 图片输入差异 | 每个 CLI 实测后再承诺，不凭其他工具表现推断 |
| 现成工具自带额外行为 | 核查权限模式、自动答复、历史扫描、额外日志，不能只隐藏按钮 |
| 复用改造维护成本 | 固定 upstream、补丁边界、退出 fork 门槛，避免持续大改却仍称轻量复用 |
| 桌面服务包装 | 处理就绪握手、令牌和 Origin、native ABI、进程所有权、关闭语义 |

用户已经认可专家建议与遗漏方向。新增的源码判断经实际 Antigravity 技术评审后形成设计基线；构建和运行结论仍留待验证。
