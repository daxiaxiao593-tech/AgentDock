## Global Constraints

- 仅 Codex / Antigravity / Claude Code；同工具可多会话，每条会话绑定固定真实目录。
- 不改 CLI/API 配置，不注入权限或恢复参数，不自动确认，不扫描或重发历史提示。
- 新 runId 隔离输出、输入、resize 和 ACK；只结束应用确认归属的进程。
- 停止或移除必须明确确认；移除不删除项目文件，停止失败不移除配置。
- 配置保存失败必须可见；旧配置不能在升级时丢失。
- 终端只在当前进程内保留显示缓冲；不新增终端全文落盘日志。
- 保留现有未提交改动，不暂存、不提交、不改 Git 身份；本次在用户指定工作目录继续整合。
- 不添加网关、编辑器、分屏、远程、团队、Shell/Kimi、系统自启或模拟统计。

## Review Focus

1. 重复创建、停止/移除与异步启动交错：只操作指定会话和 run，不误删新 run。
2. 同名不同路径、中文/空格/UNC/大小写敏感目录：按真实规范路径分组，不能全路径粗暴转小写。
3. 单个失效目录或 CLI 缺失：错误归属该会话，不能挡住其他会话启动。
4. WebSocket 重连、窗口重载、输出背压：重连同一 run，不重复启动或输入；无屏幕恢复证据时明确提示。
5. 保存失败或 schema 损坏：不以默认值覆盖原配置；持久化先成功才更新运行定义。

## 协议与数据契约

schema 2：`{schemaVersion:2, projects:[{id,rootPath,collapsed}], sessions:[{id,projectId,agent,name,launchOnOpen}], selectedSessionId}`。`agent` 仅为 `codex|agy|claude`；label 由工具表提供，cwd 从 project.rootPath 派生。

旧 schema 1 有 cwd 时迁移成一个项目、三条原 ID 会话，逐项保留启动开关；cwd 为 null 时迁移为空列表，避免创建不能启动的占位会话。加载不静默覆盖文件，后续成功保存写 schema 2。

配置命令使用 `requestId` 对应 `command-result`（`ok`、失败 `message`）；成功变更广播完整 `workspace` 和动态会话快照。保留运行命令 `start/stop/input/resize/ack`。

新增命令：`create-session {agent,cwd,name,launchOnOpen,start}`、`rename-session {sessionId,name}`、`remove-session {sessionId,runId}`、`select-session {sessionId}`、`set-project-collapsed {projectId,collapsed}`、`launch-on-open {sessionId,enabled}`、`start-all`。移除运行会话须当前 runId 一致且停止成功；被更新的选择状态应与会话列表一致。

快照中的每个会话提供 `sessionId,projectId,agent`（显示名）、`agentId`（工具键）、`name,cwd,launchOnOpen,directoryError,runtime`。空工作区合法。
